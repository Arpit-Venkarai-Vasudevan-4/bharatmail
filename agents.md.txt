Use Node 24.21.x (>=24.21.0 <25), PostgreSQL 16, and the existing npm projects. The root README.md is the canonical evaluator setup; docker-compose up starts the completed frontend, portal, API and database after the private root .env is supplied. Backend commands: npm ci, npm run build, npm run migrate, npm test. Native mobile is outside the current web delivery.

Keep API routes under /api, use parameterized SQL, preserve migrations, and never commit .env or secrets. PhoneMail addresses derive from normalized phone numbers. Do not upgrade Expo 52, React Native 0.76, or React 18 without a demonstrated compatibility need. Backend Stage 2 includes private revisioned drafts, account-scoped sync, resumable/range uploads, and durable outbox leasing. SMTP/MIME and Twilio capabilities depend on private configuration; do not assume they are enabled or trigger paid provider traffic in tests. Malware scanning and unsupported provider/contracts remain explicit release boundaries documented in the frontend handoff.
