Use Node 20+, PostgreSQL 16, and the existing npm projects. Run docker compose up -d --build for the API and database. Backend commands: npm install, npm run build, npm run migrate, npm test. Mobile commands: npm install, npx tsc --noEmit, npm start.

Keep API routes under /api, use parameterized SQL, preserve migrations, and never commit .env or secrets. PhoneMail addresses derive from normalized phone numbers. Do not upgrade Expo 52, React Native 0.76, or React 18 without a demonstrated compatibility need. Backend Stage 2 now includes private revisioned drafts, account-scoped sync, resumable/range uploads, and durable outbox leasing. SMTP/MIME transport, Twilio OTP/SMS/IVR, malware scanning, and provider callbacks remain explicitly disabled pending external provider/test-harness setup.
